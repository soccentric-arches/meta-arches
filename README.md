# meta-arches

Yocto layer for **Arches** (NVIDIA Jetson), part of the open-source Arches platform from [SoCcentric](https://soccentric.com).

It is used by [Arches-OS](https://github.com/soccentric-arches/Arches-OS), which holds the kas configuration that builds a full image.
